# Lab 1 – Databricks Fundamentals & DEV Setup

**Dataset:** [Steam Games Dataset](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset) (Kaggle)

**Note:** The original CSV file contains a formatting bug in the header row. The columns `Discount` and `DLC count` are glued together (`DiscountDLC count`). To parse the data correctly, a comma must be manually inserted between them before using this dataset.

**API:** [Steam Web API](https://steamcommunity.com/dev) – used to pull additional game data directly from Steam
